# Data Analyst Portfolio Website

This repository contains a simple personal portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — main web page content
- `style.css` — website styling
- `script.js` — small script for dynamic footer year

## How to edit the website conte

1. Open the repository in GitHub.
2. Click on `index.html`.
3. Press the pencil icon to edit.
4. Update text such as:
   - Your name
   - About section
   - Project titles
   - Skills
   - Contact email
5. Save the file.

## How to publish it on GitHub Pages

1. Go to your repository on GitHub.
2. Click `Settings`.
3. Open `Pages` from the left menu.
4. Under `Source`, choose `Deploy from a branch`.
5. Select the branch `main` and folder `/root`.
6. Click `Save`.
7. Wait a few minutes.
8. Your website will be live at:
   `https://<your-github-username>.github.io/<repo-name>/`

## Example
If your GitHub username is `johnsmith` and your repository is `data-analyst-portfolio`, the site will be:

`https://johnsmith.github.io/data-analyst-portfolio/`

## Best practice
